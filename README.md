# iris-classification-rf
# Iris Flower Classification with Random Forest

Scikit-learnを用いたアヤメ（Iris）の品種分類モデル構築プロジェクトです。  
ランダムフォレスト（Random Forest）アルゴリズムを使用して分類精度を評価します。

## 概要
* **使用データセット**: Iris dataset (Scikit-learn組み込み)
* **手法**: ランダムフォレスト分類器 (RandomForestClassifier)
* **目的**: 萼（がく）や花びらのサイズからアヤメの品種（Setosa, Versicolor, Virginica）を分類する

## 動作環境・使用ライブラリ
* Python 3.10+
* pandas
* scikit-learn
